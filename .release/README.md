# Release source contract

Native Pages automatic publication is allowed only through the hash-pinned guard configured in the provider build command. The guard binds this repository, production branch, newest exact commit and the live provenance watermark; rejects lost production ancestors, missing required files, dirty source, archive copies and superseded builds; stages a separate artifact and emits __release.json. The first guarded build must match the recorded live asset fingerprints. A later manual release must carry the same provenance file and merge its accepted source into the production branch before automation can proceed. Do not re-enable another publication lane for these targets. Preview or exceptional reviewed source changes require their own exact policy/receipt; no dirty override. Current target policies are in policies.json. The source is shared with ieduer/cf-ops-scripts release-channel-guard.mjs; update the provider-pinned hash when changing it.
